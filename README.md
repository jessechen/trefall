# Trefall

## A triangular Abelian sandpile

[Abelian sandpiles](https://en.wikipedia.org/wiki/Abelian_sandpile_model) are cellular automata that seem to intrinsically veer toward complex behavior. This is an interactive playground on a triangular grid.
